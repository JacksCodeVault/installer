How it works

Install in three steps

The interactive installer guides you through configuration and deploys everything automatically.

1

Download the installer

Fetch the install script to your server with a single curl command.

curl -fsSL https://get.nusaas.com/install.sh -o install.sh
2

Run the script

The installer prompts for your configuration and generates secure secrets.

bash install.sh
3

Access your instance

Once migrations finish, log in and start managing your business.

https://app.yourdomain.com
